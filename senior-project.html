Senior Project

Florida Atlantic University, Computer Science.

Accessible Indoor Navigation with Bluetooth Positioning

  • BLE
  • Kalman filter
  • AWS Lambda

Developed a Bluetooth-based indoor positioning system for an accessible navigation platform designed for stadiums and large venues. Built the real-time localization engine using triangulation from six BLE beacons, implementing RSSI-to-distance conversion, multilateration optimization, and Kalman filtering for accurate position tracking. Created deviation detection logic that monitors user movement against calculated routes and triggers automatic path recalculation when users go off-track. Integrated with AWS Lambda for accessibility-aware pathfinding supporting wheelchair, crutches, and default mobility profiles.
